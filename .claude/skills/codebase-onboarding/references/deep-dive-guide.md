# Deep Dive Guide

## Why these choices were made

Use this file for context that explains **historical decisions**, not
current behavior — things like:

- "We use X instead of Y because of a migration in progress"
- "This module looks over-engineered because it used to support a
  feature we removed — full cleanup is tracked in ISSUE-123"
- Known trade-offs the team accepted and why

This is exactly the kind of material that would bloat SKILL.md if it
lived there directly — it's only relevant to a small fraction of
questions, so it stays out of context until genuinely needed.
