# 📚 Reference Examples (не активна конфігурація Claude Code)

Файли в цій папці **не є частиною живої `.claude/` конфігурації** цього
репо. Claude Code їх не читає й не використовує звідси. Вони тут суто
як **навчальні приклади** речей, які фізично живуть в інших місцях:

| Приклад | Де це реально живе |
|---|---|
| `personal-skill-pr-description/` | `~/.claude/skills/pr-description/` — домашня директорія користувача, поза будь-яким repo. Персональний skill слідує за тобою по всіх проєктах, а не комітиться в конкретний repo. |
| `enterprise-managed-settings.example.json` | Файл рівня всієї організації (керує IT/admin, не окремий розробник) — деплоїться через MDM/enterprise tooling, не через `git push` у проєкт. |

## Чому взагалі показано ці приклади тут

Щоб зручно бачити **всю картину** розподілу skills за 4 рівнями пріоритету
(Enterprise → Personal → Project → Plugins) в одному місці, навіть якщо
3 з 4 рівнів фізично не належать цьому конкретному repo.

`.claude/skills/` у корені цього repo — це **Project-level** приклад
(третій рівень пріоритету). Personal і Enterprise показані тут окремо
саме для повноти картини.
